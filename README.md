# Validador Globo — V2

Validador local de criativos para cinco formatos:

- FrameAd — 1920 × 1080, até 990 KB
- Touchpoint Desktop — 1920 × 100
- Touchpoint Mobile — 430 × 140
- Pause Ads — 996 × 640, PNG, até 900 KB, transparência obrigatória
- Pause Ads Takeover — 1920 × 1080, JPG/JPEG, até 900 KB

## Recursos

- validação de dimensão, peso quando cadastrado, extensão e MIME;
- detecção de transparência para Pause Ads;
- validação de múltiplos arquivos;
- sugestão de formato pela dimensão;
- pré-visualização;
- overlays de áreas de referência para FrameAd, Touchpoint e Pause Ads Takeover;
- copiar resultado;
- funcionamento 100% local no navegador.

## Observação importante

As áreas visuais de referência não substituem o gabarito operacional oficial. O overlay do Pause Ads Takeover utiliza a referência visual enviada pelo usuário e deve ser calibrado caso seja disponibilizado o gabarito oficial em resolução/pixels.

O peso máximo do Touchpoint Imagético não foi cadastrado nesta V2 porque não foi localizado na página oficial consultada; por isso a ferramenta não reprova o arquivo por peso nesse formato.
